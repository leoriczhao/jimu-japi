# 《裂隙行者》V2

独立的 Warcraft III: The Frozen Throne 1.27a Classic SD 地图。源码依据 2026-11-18 的 V2 策划。主角 Eli 是用内置剑圣外观制作的独立近战物编。三段固定地牢有 32 个普通敌人、两次互斥升级和一名双阶段监守。

## 构建与运行

在仓库根目录运行 `python -B projects/rift-walker/build.py`。程序生成地形、通行和物编，将项目的三个 JASS 模块合并，使用 1.27.1 数据包的 Common.j 和 Blizzard.j 做标准 JASS 校验，通过常规 MPQ 归档生成 `build/RiftWalker.w3x` 及 `build/RiftWalker.manifest.json`。地形与物编的可编辑来源在 `map_data.py`。地图运行所需的模型和图标来自游戏安装。

把 `.w3x` 放进原版 1.27a 安装目录的 `Maps\Test`，在「单人游戏 → 自定义游戏」启动，保持正常速度。右键地面移动，右键敌人攻击。选中主角后按 Q 或 W，再左键点地确认方向。E 直接释放。升级选项可点按钮或按 1/2。结算后点 **Retry** 重来，也可用 `-retry`。`-help` 显示操作，`-mute` 切换声音，`-status` 显示房间、位置、生命、剩余敌人及实际生效的命中与技能计数。

## 第一轮手玩

1. 从入口往右走，接近前三个侍从。右键攻击一只，确认剑击后出现裂痕。对同一只怪打出三次连贯命中，随后走开等待约 6 秒，观察裂痕一起消失。
2. 有活敌时按 Q 并点怪群前的地面。看到裂痕后靠近按 E。观察被标记目标的裂痕清空，旁边未标记的怪也能吃回响。有空时先在无标记时按一次 E，确认冷却留在 Ready。
3. 下一组交战时，先向空地 W，再找墙边或封门测试。成功要看见实位移与 5 秒冷却。失败测试请选择贴近挡路处，避免前方尚有足够空间导致合法的短一段位移。
4. 清完第一房的 12 个敌人后，往右侧门口走。升级弹窗出现，补给最多 180 HP。选 1 看裂痕上限是否变成 4，或选 2 看 W 是否变远且冷却变短。确认开门后能走进第二房。
5. 单独测试一次失败重试。留在敌群里直到阵亡，点 Retry。回到前庭时检查 900 HP、剩余 12 敌、两个升级均未选择和技能冷却归零。

第一轮通过后，再按两条不同的升级路线正常通关。记录结算用时、选择、Boss 出招和明显的读招困难。遇到问题记录房间、按键或点击顺序、看到的结果，以及当时的 HUD 截图。
